# 神寂·巡礼 · 月见（Shenji Pilgrimage — Luna Edition）

《神寂·巡礼》的旁支版本：同一座庭，另一种巡礼。
把体验重心从压迫式恐怖平移到「诡美 + 共情 + 被理解」。

## 与主线的差异
- **月白色板**：走廊尽头是月晕、海面泛月银、镜室带月蓝
- **熄灯式崩塌**：替代血色——世界一寸寸暗下去，只剩祂的瞳还亮着
- **月之哼鸣**：程序合成的五声音阶垫音，随凝视浮现
- **设置菜单**：灵敏度 / 视野 / 防晕晃动 / 温和模式 / 音效
- **大模型审判**：九酒之问的「自定义回答」由 agnes-2.5-flash 判定并悲悯回应，附**巡礼札记**
- **月相 HUD**：注视值以 ●○ 月相显示

## 构建
```bash
export ANDROID_HOME=<sdk路径> JAVA_HOME=<jdk17路径>
gradle assembleDebug
```
